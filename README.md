# morphyAI

Чат с моделями Coarena на Next.js (App Router) + TypeScript + Tailwind-стилях через CSS-переменные.

## Что умеет
- Стриминг ответов, кнопка «Стоп», «Повторить ответ», «Копировать».
- Вложения: текстовые файлы, PDF, изображения и ZIP-архивы с текстовыми/код-файлами; файлы из ответов можно скачивать отдельно или ZIP-архивом.
- До 120 000 токенов на ответ (фактический предел зависит от модели и API).
- Фоновая генерация (не веб-поиск): ответы продолжаются после закрытия вкладки; результат хранится до 24 часов в памяти процесса.
- Markdown, таблицы, подсветка кода, формулы KaTeX. Сырой HTML от модели не выводится.
- Блоки кода: «Копировать» и «Скачать» с правильным расширением. Формат `lang:путь/файл.ext` задаёт имя файла.
- Выбор модели из `GET /api/models` (кэш 5 мин), выбор запоминается в браузере.
- Оценки 👍/👎 через серверный прокси `/api/feedback`. Ошибки оценки не ломают чат.
- История в IndexedDB: новый чат, переименование, удаление, поиск (Ctrl+K), экспорт в `.md` и `.json`.
- Пул ключей на сервере: автопереключение при 429, 402, 401, 403 и 5xx, cooldown и отключение ключей.

## Настройка
1. `npm install`
2. Скопируйте `.env.example` в `.env.local` и укажите `COARENA_API_KEYS=ключ1,ключ2`.
   Ключи только на сервере, в браузер не попадают.
3. `npm run dev`, затем откройте http://localhost:3000

## Тесты и сборка
    npm test
    npm run build

## Деплой на Netlify
1. Подключите репозиторий или загрузите архив.
2. Build command: `npm run build`. Netlify определит Next.js автоматически.
3. Site configuration → Environment variables: `COARENA_API_KEYS`, при необходимости `COARENA_BASE_URL`, `KEY_STRATEGY`, `ALLOWED_ORIGIN`.
4. Перевыпустите ключи, которые попали в переписку, и используйте только новые.

## Деплой на Render
Создайте Blueprint из репозитория с помощью `render.yaml` или настройте сервис вручную как **Web Service**:
- Runtime: Node
- Build command: `npm install && npm run build`
- Start command: `npm run start`

Не создавайте Static Site: приложению нужны серверные API-маршруты. Добавьте `COARENA_API_KEYS` в Environment Variables Render.
Фоновые задачи хранятся в памяти процесса и теряются при перезапуске или новом деплое. Для надёжного хранения между перезапусками нужен внешний Redis/БД.

## Допущения (не подтверждены документацией Coarena)
- Формат тела `POST /feedback`: `{model, rating: 1 | -1}`. Задан в `lib/feedback.config.ts`.
- Классификация ошибок по HTTP-статусу. Квота определяется по коду 402.
- `Retry-After` в секундах.
- Поддержка vision и файлов зависит от модели и не проверена.

## Ещё не сделано
- Тесты интерфейса (React Testing Library) и e2e (Playwright).
- Общий rate limit на внешнем store (Upstash Redis). Сейчас счётчики в памяти инстанса.
- PDF без текстового слоя (скан) не распознаётся: нужен OCR, это отдельная задача.

## Допущения, которые стоит проверить
- Версия `pdfjs-dist` 4.4.168 и путь `legacy/build/pdf.mjs` для неё. Если сборка не находит путь, поменяйте версию.
- Распознавание речи идёт через Web Speech API: в Chrome и Safari работает, в Firefox кнопки нет.
- Режим сравнения шлёт один и тот же вопрос двум моделям параллельно, поэтому расходует лимит в два раза быстрее.

## Админка
`GET /api/admin/keys-status` с заголовком `Authorization: Bearer <ADMIN_TOKEN>` возвращает состояние каждого ключа
(активен, cooldown, отключён), счётчики и маски. Сами ключи не возвращаются. Нужен `ADMIN_TOKEN` длиной от 16 символов.
